# Maintainers

## AHRQ Quality Indicators Repository

This repository is maintained on behalf of the Agency for Healthcare Research and Quality (AHRQ) Quality Indicators (QI) Program.

## Repository Maintainers

### Primary Maintainer

**AHRQ Quality Indicators Support Team**  
Email: QISupport@ahrq.hhs.gov

The AHRQ QI Support Team is responsible for:

- Reviewing and triaging issues submitted through GitHub
- Managing pull requests and repository updates
- Maintaining repository documentation
- Coordinating software and technical specification releases
- Responding to questions from repository users
- Ensuring compliance with applicable security and governance requirements

### Development and Operations Support

The repository is supported by the AHRQ Quality Indicators development and operations team under contract with AHRQ.

Responsibilities include:

- Software maintenance and updates
- Security patching and vulnerability remediation
- Build and release management
- Repository administration
- Infrastructure and DevOps support

## Security Issues

Do not report security vulnerabilities through public GitHub Issues.

Please refer to the SECURITY.md file for instructions on reporting potential security concerns.

## Issue Reporting

For general questions, bug reports, or feature requests:

1. Search existing GitHub Issues before creating a new issue.
2. Provide sufficient detail to reproduce the issue.
3. Include software version information when applicable.

## Repository Governance

Repository maintainers reserve the right to:

- Close duplicate issues
- Close issues lacking sufficient information
- Reject pull requests that do not align with project objectives
- Remove content that violates project policies or applicable laws and regulations

## Response Expectations

Maintainers will make reasonable efforts to review issues and pull requests in a timely manner; however, response times may vary based on project priorities and available resources.
